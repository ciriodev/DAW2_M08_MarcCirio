# Marc Cirio Fuentes — Portfolio

Portfolio profesional de Marc Cirio Fuentes, desarrollado con HTML, CSS y JavaScript vanilla.

## Objetivo

Presentar de forma clara y profesional el perfil, experiencia, formación y futuras evidencias de proyectos de desarrollo web.

## Tecnologías

- HTML5 semántico
- CSS3
- JavaScript vanilla
- Responsive design
- Intersection Observer API
- LocalStorage
- Git / GitHub

## Estructura

```text
portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Visualización local

No requiere instalación ni dependencias.

1. Clona el repositorio.
2. Abre `index.html` en el navegador.

Para una experiencia más cercana a producción puedes usar la extensión Live Server de VS Code.

## Publicación

El proyecto está preparado para desplegarse en GitHub Pages, Netlify o Vercel.
